# Screenshots

Add publication screenshots here (PNG or JPEG, ≤ 4 MiB, ≤ 8192 px per side) and reference them from the READMEs,
for example `![WakaTime card](docs/images/overview.png)`. Token Monitor's plugin README preview rejects SVG/WebP/HTML
images and absolute non-raw.githubusercontent URLs.

Expected files:

- `overview.png` — the Home card with upload state, today's tokens and the WakaTime day.
- `settings.png` — the plugin settings form.

Do not include API keys, OAuth tokens, personal project names or account emails in screenshots.
